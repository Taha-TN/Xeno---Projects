## 🚀 Projects

### Xeno Legends

**Xeno Legends** is a Dragon Ball Legends private server project designed to provide a different experience from the original game.

It includes a wide range of resources and features, offering users access to significantly more content and resources than the standard version of Dragon Ball Legends.

**Highlights:**
- Expanded resources
- Private-server environment
- Additional resources compared to the original game
- Built around the Dragon Ball Legends experience

---

### Bandai Creator

**Bandai Creator** is a tool for creating Bandai accounts that can be used to link with Dragon Ball Legends accounts.

It provides a simple way to create the required account credentials for connecting Dragon Ball Legends accounts with Bandai services.

**Highlights:**
- Bandai account creation
- Simple account setup
- Designed for Dragon Ball Legends account linking

---

### Rezzy Legends

**Rezzy Legends** is a Dragon Ball Legends summon simulator.

The project recreates the experience of performing summons without requiring the actual game, allowing users to experiment with different summon scenarios and explore available characters.

**Highlights:**
- Dragon Ball Legends summon simulation
- Character-based summon system
- Experiment with summons without using real in-game resources
